## Test cases considered but explicitly out of scope for this Phase 1 audit

- Full concurrency/race-condition testing (two browser tabs editing the same stock simultaneously) — flagged as an open question (`condition-open-questions.md` Q-07) since `localStorage` has no locking; not something a UI-level fix alone can resolve.
- Load/performance testing of `getDemoStocks()`'s per-read migration pipeline at scale (MED-16) — recommend as a separate performance audit if the demo dataset grows significantly.
